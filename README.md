# Password Generator

A free, privacy-friendly password generator that runs entirely in your browser.

**Live Demo:** [https://solix-generator.github.io/password-generator/](https://solix-generator.github.io/password-generator/)

## Features
- Generate strong random passwords
- Generate memorable (word-based) passwords
- Adjustable length (8–64 characters)
- Options for uppercase, lowercase, numbers, and symbols
- Password strength indicator
- One-click copy to clipboard
- 100% client-side — nothing is ever sent to a server

## How to use
1. Open the [live demo](https://solix-generator.github.io/password-generator/)
2. Choose Random or Memorable mode
3. Adjust the length and options
4. Click **Generate Password**
5. Click **Copy**
